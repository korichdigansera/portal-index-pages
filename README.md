# portal-index-pages

## 项目简介

这是一个用于归档和发布多个独立 HTML 页面的仓库。本仓库不针对任何特定网站或域名，仅作为静态页面集合的存储与展示空间。每个页面独立存放，互不干扰，便于索引和访问。

## 目录说明

```
portal-index-pages/
├── index.html          # 根目录入口页，列出所有归档页面链接
├── pages/              # 存放所有独立 HTML 页面
│   ├── page-001.html
│   ├── page-002.html
│   └── ...
└── README.md           # 本文件
```

- `index.html`：仓库首页，提供页面导航。
- `pages/`：所有归档页面均放置在此目录下，按需命名。

## 页面归档说明

- 每个页面为一个完整的独立 HTML 文件，不依赖外部资源（除非必要）。
- 页面内容保持简洁，结构清晰，便于阅读和引用。
- 归档页面不涉及任何商业、营销或推广性质的内容。
- 页面命名建议使用英文或数字，避免特殊字符。

## 维护说明

- 欢迎提交新的独立 HTML 页面，请放置于 `pages/` 目录下，并在 `index.html` 中添加对应链接。
- 请确保页面内容不违反法律法规及 GitHub 社区准则。
- 如需修改或删除已有页面，请通过 Pull Request 提交变更。
- 本仓库由维护者不定期整理，保持页面列表的整洁与可访问性。

## 其他

本仓库仅用于技术归档与页面展示，不提供任何形式的服务或背书。如有疑问，请通过 Issue 联系。
